# 3W Link

Windows companion app for 3W Sim Panels by 3Wire Innovations.

**Download:** [3WLink-Setup.exe](https://github.com/Dornis-Home-Portal/3W-Link-Releases/releases/latest/download/3WLink-Setup.exe) (latest version, Windows 10/11, no admin rights needed).

If Windows shows "Windows protected your PC", click **More info → Run anyway**. The installer is signed by Arlynn Dornis (3Wire Innovations).

Installed copies update themselves. This repository holds only the installer and update files.
